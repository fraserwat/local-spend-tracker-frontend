Decision log

1

No confirmed source for "X transactions, total £Y"

CursorPagination doesn't compute a total row count cheaply. Either add a small aggregate (count/sum) query on the same filtered queryset, or drop the summary line from MVP.

2

Date-range filter param names aren't defined

Recommend date_from/date_to, validated the same way the sort field is — an explicit allow-list before .filter(), not left implicit.

3

Recipient autocomplete needs a council scope

ARCHITECTURE.md describes /spend/api/recipients/?q= with no council param. Unscoped, it returns names across every loaded council — noisy and wrong. Needs ?council=<slug>&q=.

4

Default sort order isn't locked

Recommend date descending — table opens on the most recent spend, which also reads naturally against the coverage badge's "data through month X" framing.

5

CSV export rate-limit needs a user-facing message

Export throttles at 5/min with no auth to key on. A raw HTTP 429 isn't an acceptable error surface — needs a plain-language message on the export button/flash.
